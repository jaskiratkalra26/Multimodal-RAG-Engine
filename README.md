# Multimodal RAG Engine

A Python-based **Multimodal Retrieval-Augmented Generation (RAG) Engine** that processes and retrieves information from multiple data modalities such as **text, PDFs, and images**, and augments generation using retrieved context.

This project demonstrates a modular and scalable approach to building a **multimodal RAG pipeline**, suitable for real-world AI applications like document QA systems, knowledge assistants, and intelligent search engines.

---

## 🚀 Features

- 📄 PDF Processing – Extracts and processes textual content from documents  
- 🖼️ Image Understanding – Supports visual data embedding  
- 🔎 Vector-Based Retrieval – Uses embeddings for semantic similarity search  
- 🤖 Retrieval-Augmented Generation – Enhances LLM responses using retrieved context  
- 🧩 Modular Architecture – Easy to extend and customize  
- ⚡ Phase-wise Implementation – Clear separation of logic for better maintainability

## 🛠️ Installation

### Clone the Repository
```bash
git clone https://github.com/jaskiratkalra26/Multimodal-RAG-Engine.git
cd Multimodal-RAG-Engine
```

### Create Virtual Environment
```bash
python -m venv venv
source venv/bin/activate
```

### Install Dependencies
```bash
pip install -r requirements.txt
```
